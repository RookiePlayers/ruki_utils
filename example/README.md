# ruki_utils_example

Minimal demo app for `ruki_utils`.

## What it shows

- `ScreenUtils.configure(...)` setup
- responsive sizes (`.responsive`, `.responsiveFont`, `.vw`, `.vh`)
- safe-area padding helpers
- platform flags (`isWeb`, `isAndroid`, `isIos`, `isTablet`)
- color helpers (shade/tint/contrast text)

## Run it

```bash
flutter run --target=example/lib/main.dart
```
